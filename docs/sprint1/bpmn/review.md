# Протокол рецензування BPMN-моделей

Рецензент перевіряє модель за чек-листом нотації (10 пунктів), не власну діаграму.
Чек-лист (скорочено): початкова/кінцева подія є; кожен шлюз має ≥2 виходи з підписаними
умовами; типи шлюзів відповідають семантиці (XOR — виключне, AND — паралельне);
доріжки відповідають ролям з product.md; потоки повідомлень — штрихові й між пулами;
об'єкти даних приєднані пунктиром без стрілки; підпроцес позначено; немає висячих
(не з'єднаних) елементів; назви задач — дієслово + об'єкт; анотації пояснюють нетривіальні
правила (таймери, цикли).

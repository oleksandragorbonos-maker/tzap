# Таблиці елементів бізнес-процесів (вхідні дані для BPMN)

Команда: С · Продукт: №1 «ШопЛайн» · Спринт: 1 · Дата: 22.09.2026 · Автор: Горбонос Олександра (ІТ)

Джерело: легенда продукту «ШопЛайн», розділ 2.3 [project-context.md](../../../project-context.md).
Тип шлюзу вказано біля кожного розгалуження. Норматив ≥3 різних типи шлюзів у наборі
виконує вже модель 1 сама по собі: XOR за даними, XOR за подіями, AND. Моделі 2 і 3
додають лише повторні XOR — це очікувано й не є помилкою, головне, що набір
загалом покриває три типи.

Легенда задає трирівневу структуру учасників: **Покупець** — окремий пул;
**Магазин** — один пул з лініями (Сайт/Система, Менеджер, Склад, Бухгалтерія,
Адміністратор — за процесом); **зовнішні учасники** (Платіжний шлюз, Служба
доставки) — окремі пули-«чорні скриньки», з якими Магазин обмінюється лише
повідомленнями. Це відображено в кожній таблиці нижче.

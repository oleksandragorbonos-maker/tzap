## Правила standup у командному чаті

Standup — щоденне коротке повідомлення в чаті команди, яке кожен учасник пише
самостійно (без дзвінка) у міжзаняттєвий період (будні дні між очними зустрічами).

**Формат повідомлення:**

```
[Ім'я], [дата]
Зроблено: коротко, що встиг(ла) зробити за попередній день
Блокує: що заважає рухатись далі (або "немає блокерів")
```

**Правила:**

1. Кожен учасник команди пише своє повідомлення в чат **щодня** до 20:00, крім
   вихідних та днів очних занять (тоді статус озвучується усно).
2. Повідомлення має бути коротким — 2–4 рядки, без деталей, які не впливають
   на роботу команди.
3. Якщо є блокер, який учасник не може вирішити сам — тегати Коротку Ксенію
   (СМ) прямо в повідомленні, щоб він потрапив у фокус на найближчій зустрічі.
4. СМ раз на день переглядає всі повідомлення, синхронізує статуси в таблиці
   вище і за потреби виносить блокери на обговорення команди.
5. Якщо учасник не написав standup два дні поспіль без попередження — СМ
   пише йому особисто для уточнення статусу.
